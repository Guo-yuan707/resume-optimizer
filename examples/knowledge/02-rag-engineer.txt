岗位名称:大模型应用工程师(RAG 方向)(示例岗位 02)
公司类型:企业服务(To B)科技公司
工作地点:深圳

【岗位职责】
1. 负责企业级知识库问答系统的研发,核心是 RAG 链路:文档解析 → 切块 → 向量化 → 检索 → 生成。
2. 持续优化检索效果:调整切块策略、优化 embedding、引入重排(Rerank)机制。
3. 设计 prompt 模板体系,针对不同业务场景调优生成质量,降低幻觉。
4. 建设评测体系,用测试集评估检索准确率和回答质量。

【任职要求】
1. 计算机相关专业本科及以上学历,Python 基础扎实,熟练使用标准库和常用第三方库。
2. 理解 RAG 全流程原理,能讲清楚"为什么切块会影响检索质量"。
3. 熟悉至少一种向量数据库,如 Milvus、Qdrant、Chroma,了解其基本用法和适用场景。
4. 熟练使用 Git,有良好工程习惯,重视代码可读性和测试覆盖。
5. 了解基础算法:余弦相似度、TF-IDF、文本预处理等。
6. 有 HTTP API 开发经验,熟悉 FastAPI 或 Flask。

【加分项】
- 有线上 RAG 系统优化经验,能用量化指标说明优化效果。
- 熟悉 bge、m3e 等中文 embedding 模型。
- 有对中文文档进行切块和清洗的实践经验。
