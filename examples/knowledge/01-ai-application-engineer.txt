岗位名称:AI 应用开发工程师(示例岗位 01)
公司类型:中小型 AI 创业公司
工作地点:杭州

【岗位职责】
1. 负责基于大语言模型(LLM)的 AI 应用开发,包括对话系统、知识库问答、智能客服等产品。
2. 参与 RAG(检索增强生成)技术方案的落地,建设向量知识库,优化检索质量与生成效果。
3. 与算法团队协作,完成 prompt 工程调优,提升模型输出的稳定性和准确性。
4. 负责 AI 应用的接口设计与部署上线,保证系统的稳定性和可维护性。

【任职要求】
1. 本科及以上学历,计算机、软件工程等相关专业,具备扎实的 Python 编程基础。
2. 熟悉常见的 AI 开发框架,如 LangChain、LlamaIndex,或至少深入理解其中一种。
3. 了解大模型 API 的调用方式,熟悉 OpenAI 兼容接口或 DeepSeek 等国产大模型。
4. 了解 RAG 相关技术,包括文本切块、向量化、相似度检索、向量数据库(如 Milvus、Chroma)。
5. 有 FastAPI、Flask 等 Web 框架使用经验,能独立完成接口开发和部署。
6. 具备良好的代码习惯,熟悉 Git 版本管理,有单元测试意识。
7. 了解流式输出、Function Calling、Agent 等进阶能力者优先。

【加分项】
- 有完整 LLM 应用从 0 到 1 落地的项目经验。
- 熟悉 Docker 容器化部署。
- 有向量数据库实际使用经验。
